## ข้อ 1: หาตำแหน่งของ 0 ด้วย Binary Search

**ไฟล์:** `src/FindZeroIndex.java`

**โจทย์:** มี array `a1[1...n]` ที่เก็บตัวเลขบวกเรียงลำดับและไม่ซ้ำกัน ส่วน `a2[1...n+1]` คือ `a1` ที่ถูกแทรกค่า 0 ไว้ตรงตำแหน่งใดตำแหน่งหนึ่ง ต้องหาตำแหน่ง (index) ของ 0 ใน `a2` โดยใช้เวลาไม่เกิน **O(log n)**

**แนวคิด:** เปรียบเทียบ `a1[mid]` กับ `a2[mid]` แทนที่จะเทียบค่ากับ 0 โดยตรง
- ก่อนตำแหน่งของ 0 → `a1[i] == a2[i]` เสมอ (ค่ายังไม่เลื่อน)
- ตั้งแต่ตำแหน่งของ 0 เป็นต้นไป → `a1[i] != a2[i]` เสมอ (ค่าถูกเลื่อนขวา 1 ตำแหน่งเพราะ 0 แทรกเข้ามาคั่น)

เนื่องจากรูปแบบนี้เป็น "เท่ากันทั้งหมดทางซ้าย แล้วสลับเป็นไม่เท่ากันทั้งหมดทางขวา" (ไม่มีสลับไปมา) จึงสามารถตัดปัญหาครึ่งหนึ่งทิ้งได้แบบ Binary Search ทำให้ได้ความเร็ว O(log n)

**ข้อมูลตัวอย่าง:**
```
a1: 1, 3, 4, 6, 7, 8, 9, 20
a2: 1, 3, 0, 4, 6, 7, 8, 9, 20
```

**ผลลัพธ์:**
```
ตำแหน่งของ 0 คือ index ที่ 3
```

## ข้อ 2: รวม Array ที่จัดเรียงแล้ว (Merge Sort)

**ไฟล์:** `src/MergeSortCaseStudy.java`

**โจทย์:** จากฟังก์ชัน `sort()` ที่ทำหน้าที่แบ่ง array ออกเป็น 2 arrays แล้วเรียก sort ซ้ำแบบ recursive (divide step ของ Merge Sort) ให้เขียนฟังก์ชัน **`merge()`** เพื่อรวม 2 arrays ที่เรียงแล้วกลับเป็น array เดียวที่เรียงลำดับถูกต้อง

**แนวคิด:** ใช้ pointer 2 ตัวชี้ไปที่ `left` และ `right` เทียบค่าคู่แรกของทั้งสอง array แล้วหยิบตัวที่น้อยกว่าใส่ผลลัพธ์ก่อน ขยับ pointer ไปเรื่อย ๆ จนกว่า array ใด array หนึ่งหมด แล้วคัดลอกส่วนที่เหลือของอีก array ที่ยังไม่หมดตามเข้าไป

**ข้อมูลตัวอย่าง:**
```
A[0...7] = 15, 3, 9, 31, 11, 17, 7, 23
```

**ผลลัพธ์:**
```
ก่อนเรียง: 15 3 9 31 11 17 7 23
หลังเรียง: 3 7 9 11 15 17 23 31
```

## ข้อ 3: Insertion Sort และ Quick Sort

**ไฟล์:** `src/SortingCaseStudy.java`

**ข้อมูลตัวอย่าง (ใช้ร่วมกันทั้งสองข้อย่อย):**
```
A[0...7] = 15, 3, 9, 31, 11, 17, 7, 23
```

### 3.1 Insertion Sort

หยิบสมาชิกทีละตัว (เริ่มจากตัวที่ 2) แล้วแทรกเข้าไปในตำแหน่งที่ถูกต้องของส่วนที่เรียงแล้วทางซ้าย เหมือนการจัดไพ่ในมือ

**ทุกขั้นตอน:**
```
เริ่มต้น:              15  3  9  31  11  17  7  23
รอบที่ 1 (แทรก 3):     3  15  9  31  11  17  7  23
รอบที่ 2 (แทรก 9):     3   9 15  31  11  17  7  23
รอบที่ 3 (แทรก 31):    3   9 15  31  11  17  7  23   (ไม่เปลี่ยน)
รอบที่ 4 (แทรก 11):    3   9 11  15  31  17  7  23
รอบที่ 5 (แทรก 17):    3   9 11  15  17  31  7  23
รอบที่ 6 (แทรก 7):     3   7  9  11  15  17 31  23
รอบที่ 7 (แทรก 23):    3   7  9  11  15  17 23  31
```
**ผลลัพธ์สุดท้าย:** `3, 7, 9, 11, 15, 17, 23, 31`

### 3.2 Quick Sort (pivot = ตำแหน่งสุดท้ายของ array แต่ละช่วง)

ใช้เทคนิค Lomuto Partition: เลือกตัวสุดท้ายเป็น pivot แล้วจัดให้ค่าที่ ≤ pivot อยู่ฝั่งซ้าย ค่าที่ > pivot อยู่ฝั่งขวา จากนั้นเรียก quickSort แบบ recursive กับแต่ละครึ่งย่อย

**ทุกขั้นตอนการ partition:**
```
เริ่มต้น: 15 3 9 31 11 17 7 23

Partition ที่ 1 (pivot=23): 15 3 9 11 17 7 23 31   -> pivot 23 อยู่ index 6
Partition ที่ 2 (pivot=7):  3 7 9 11 17 15 23 31   -> pivot 7 อยู่ index 1
Partition ที่ 3 (pivot=15): 3 7 9 11 15 17 23 31   -> pivot 15 อยู่ index 4
Partition ที่ 4 (pivot=11): 3 7 9 11 15 17 23 31   -> pivot 11 อยู่ index 3 (ไม่เปลี่ยน)
```
**ผลลัพธ์สุดท้าย:** `3, 7, 9, 11, 15, 17, 23, 31` (ตรงกับ Insertion Sort)

## ข้อ 4: Hash Table แบบ Chaining

**ไฟล์:** `src/HashTableChaining.java`

**โจทย์:** เพิ่มค่า `5, 28, 19, 15, 20, 33, 12, 17, 10` ลงในตารางแฮชขนาด **9 ช่อง** โดยใช้แฮชฟังก์ชัน **h(k) = k mod 9** และแก้ปัญหาการชนกัน (collision) ด้วยวิธี **Chaining** (ต่อเป็นลิสต์ในช่องเดียวกัน)

**คำนวณ h(k) ของแต่ละค่า:**

| ค่า (k) | h(k) = k mod 9 |
|---|---|
| 5 | 5 |
| 28 | 1 |
| 19 | 1 |
| 15 | 6 |
| 20 | 2 |
| 33 | 6 |
| 12 | 3 |
| 17 | 8 |
| 10 | 1 |

**สถานะตารางแฮชหลังใส่ครบทุกค่า:**

| ช่อง (index) | Chain (ลิสต์) |
|---|---|
| 0 | - |
| 1 | 28 → 19 → 10 |
| 2 | 20 |
| 3 | 12 |
| 4 | - |
| 5 | 5 |
| 6 | 15 → 33 |
| 7 | - |
| 8 | 17 |

**อธิบายการชนกัน:**
- **ช่อง 1:** ค่า 28, 19, 10 หารด้วย 9 เหลือเศษ 1 เท่ากันทั้งสามค่า → เกิดการชนกัน 2 ครั้ง จึงต่อเป็น chain 3 ตัว (28 → 19 → 10 ตามลำดับที่ใส่)
- **ช่อง 6:** ค่า 15, 33 หารด้วย 9 เหลือเศษ 6 เท่ากัน → เกิดการชนกัน 1 ครั้ง จึงต่อเป็น chain 2 ตัว (15 → 33)
- **ช่องอื่น ๆ** (0, 4, 7) ไม่มีค่าใดตกลงมาจึงว่างเปล่า

| ข้อ | หัวข้อ | ความซับซ้อน (Time Complexity) |
|---|---|---|

| 2 | Merge (ส่วนหนึ่งของ Merge Sort) | O(n) ต่อการ merge, รวมทั้งหมด O(n log n) |
| 3.1 | Insertion Sort | O(n²) |
| 3.2 | Quick Sort | เฉลี่ย O(n log n), เลวร้ายสุด O(n²) |
